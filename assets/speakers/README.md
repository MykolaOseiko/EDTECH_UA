# Ручне наповнення спікерів

16 позицій зліва направо, зверху вниз. Картки розміщені в `index.html`, блок `speaker-grid`.

Для кожної позиції (наприклад, 01):
- Замініть `assets/speakers/speaker_01.jpg` своїм фото, зберігши назву. Рекомендований формат — 800 × 1000 px (4:5).
- У `index.html` замініть видимий текст `name_01`, `position_01`, `company_01` на ім’я, посаду та компанію. Ідентифікатори `id` можна залишити.
- Оновіть `alt="name_01"` на ім’я експерта.
- У елементі `id="linkedin_link_01"` додайте `href="https://www.linkedin.com/in/профіль/"`, видаліть `aria-disabled="true"`, а видимий текст `linkedin_link_01` замініть на `LinkedIn`.

Номери 01–16 є позиціями, а не закріпленими людьми: на будь-яку позицію можна поставити будь-якого спікера.
