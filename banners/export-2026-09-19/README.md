# EdTech Ukraine — банери

Погоджена англомовна версія з книгою: NOVEMBER 3 • KYIV.

## PNG

П’ять окремих адаптацій: 1080×1350, 1080×1920, 1920×1080, 1600×400 та 1080×1080 px.
Композиції створені вбудованим ImageGen, потім експортовані до точних розмірів пропорційно, без деформації. Для вузького формату 1600×400 чорний фон розширено з боків, щоб зберегти всі елементи. Промпти збережено в generation.json.

## Illustrator

`edtech-editable-1920x1080.svg` — реконструкція горизонтального макета для Illustrator, не нативний AI і не повністю векторна ілюстрація.
Текст, рік, дата, адреса сайту, фон та лінія редагуються окремо. Книга і логотип — вбудовані растрові елементи з погодженого банера, у групах із масками. Реконструкція може мати невеликі типографічні відмінності від PNG.

Встановіть шрифт Inter (Bold та ExtraBold), відкрийте SVG в Adobe Illustrator і виберіть Save As → Adobe Illustrator (.ai). Або запустіть `save-as-ai.jsx` через File → Scripts → Other Script. Скрипт збереже AI поруч із SVG. Illustrator у поточному середовищі відсутній, тому нативний AI та імпорт SVG у ньому не перевірялися.
